# Next.js App Router starter

This project uses Next.js App Router, TypeScript strict mode, and Tailwind CSS 4.

## Install

```bash
npm install
```

For a fresh project, install Tailwind CSS and its PostCSS integration with:

```bash
npm install -D tailwindcss @tailwindcss/postcss postcss
```

## Development

```bash
npm run dev
```

The app is available at [http://localhost:3000](http://localhost:3000). Start building from `src/app/page.tsx`.

## Source structure

```text
src/
  app/            # App Router routes and layouts
  components/ui/  # Reusable UI components
  data/           # Static or seed data
  types/          # Shared TypeScript types
```
